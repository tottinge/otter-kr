# Architecture Decision Records

ADRs capture durable decisions and their reasoning. They are not implementation tasks and do not
have iteration status. `BACKLOG.md` contains the smaller admissions that implement or validate
these decisions.

Use the next integer filename (`NNNN-short-title.md`). If a decision changes, add a new ADR that
supersedes the old one rather than rewriting history.

Each ADR should state status, context, decision, and consequences.
